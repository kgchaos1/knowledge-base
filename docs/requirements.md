# PKM 系统需求文档

## 1. 项目概述

### 1.1 项目背景
个人知识管理（PKM）系统，用于采集、整理和管理分散在各平台的个人知识内容。

### 1.2 核心目标
- **集中采集**：从知乎、语雀等平台自动采集个人内容
- **AI 增强**：利用 AI 自动生成摘要、标签和分类
- **离线阅读**：通过 Obsidian 插件实现本地同步和离线访问
- **数据安全**：完整备份机制，保证数据不丢失

### 1.3 用户角色
- **管理员**：通过网页管理内容、配置数据源、触发 AI 处理
- **阅读用户**：通过 Obsidian 插件同步笔记并离线阅读

## 2. 功能需求

### 2.1 网页管理端

#### 2.1.1 用户认证
- 单用户登录系统
- 基于会话的身份验证
- 密码使用 PBKDF2 加密存储
- 支持 HTTPS 和临时 HTTP 测试模式

#### 2.1.2 笔记管理
- 查看笔记列表（分页、排序、筛选）
- 查看笔记详情（标题、正文、摘要、标签、来源）
- 删除笔记（单条或批量）
- 支持 Markdown 格式显示

#### 2.1.3 数据源管理
- 添加/编辑/删除数据源
- 支持的平台：知乎收藏夹、语雀、抖音、微信（部分未完成）
- 配置定时同步任务
- 查看同步任务状态和历史

#### 2.1.4 文件导入
- 支持 UTF-8 Markdown/文本文件
- 单文件最大 2MB
- 导入前预览
- 自动去重

#### 2.1.5 AI 处理
- 手动触发笔记的 AI 摘要生成
- 支持多个 AI 提供商：
  - Anthropic（Claude）
  - OpenAI
  - DeepSeek
  - 本地 Ollama
- 批量处理支持

#### 2.1.6 设备管理
- 生成配对码（10分钟有效）
- 查看已配对设备列表
- 撤销设备访问权限

#### 2.1.7 备份与恢复
- 每日自动备份（数据库 + 图片）
- 手动触发备份
- 下载备份文件
- 隔离环境恢复验证

### 2.2 Obsidian 插件

#### 2.2.1 设备配对
- 输入配对码进行设备注册
- 凭证保存到 Obsidian SecretStorage
- 支持断开设备（清除本地凭证）

#### 2.2.2 内容同步
- 增量同步（基于快照版本）
- 笔记转换为 Markdown 格式
- 图片本地化（SHA256 内容寻址）
- 本地修改冲突保护

#### 2.2.3 接收范围
- 全部笔记
- 选定数据源（多选）

#### 2.2.4 自动同步
- 前台定时同步（5/15/30/60分钟）
- 仅在 Obsidian 可见时运行
- 支持手动同步

#### 2.2.5 测试模式
- 临时免配对模式（服务端需启用）
- 用于公开内容测试
- 不发送任何凭证

### 2.3 数据采集

#### 2.3.1 知乎收藏夹
- 自动获取收藏夹文章列表
- 爬取文章正文
- 下载图片并本地化
- 支持增量更新

#### 2.3.2 通用采集能力
- 去重机制（基于 URL）
- 图片 SHA256 去重
- 失败重试机制
- 任务状态追踪

### 2.4 非功能需求

#### 2.4.1 性能
- 笔记列表分页加载
- 图片懒加载
- 同步协议批量获取（最多50条/批次）

#### 2.4.2 安全
- 密码 PBKDF2-SHA256 加密（600,000 轮）
- 设备 token 256位随机生成
- 只读设备权限隔离
- CSRF 保护（严格 Origin 检查）
- 登录限流保护

#### 2.4.3 可用性
- 同步冲突保留本地修改
- 笔记删除前确认
- 明确的错误提示
- 操作日志记录

#### 2.4.4 可维护性
- 完整的单元测试覆盖
- 版本化部署脚本
- 数据库迁移支持
- 备份与恢复机制

## 3. 约束与限制

### 3.1 当前限制
- 仅支持单用户
- HTTP 明文传输（HTTPS 待域名和证书）
- 不支持双向编辑
- 不支持多设备冲突合并
- 语雀、微信、抖音采集未完成

### 3.2 技术约束
- Python 3.11+
- Node.js 用于前端测试和插件构建
- SQLite 数据库
- Obsidian 1.11.4+（插件 SecretStorage API）

### 3.3 运行环境
- 服务器：Linux + Docker
- 客户端：Windows/Mac/Linux/Android/iOS（通过 Obsidian）
