# PKM Obsidian Connector 0.1.2 临时免配对内测

## 要求与安装

Obsidian 1.11.4及以上（配对模式使用官方SecretStorage API），Windows/Android兼容源码；尚未在实际Obsidian宿主或K70运行验收。只在独立测试Vault试用，不向已有个人库直接安装。

解压插件ZIP后，将pkm-connector目录完整放到测试Vault的.obsidian/plugins/下。在Obsidian设置中管理第三方插件并启用PKM Connector。这是手动安装的本地内测插件，不在官方社区目录；不需要另外安装Python或Node运行环境。

## 临时免配对测试模式（默认开启）

**危险：服务器启用测试模式后，任何人都可以读取服务器数据。仅用于用户已批准的临时公开资料测试，不适合私人数据或生产服务。** 插件开关不能开启服务器测试模式，管理员必须另行配置服务器；本次交付已由管理员在默认临时测试服务器启用，插件自身不修改后端或部署配置。

打开插件设置，检查服务器地址（默认临时IP），保持「临时免配对测试模式」开启，点击「立即同步」。无需配对码或token，设备名称、配对码、配对和断开按钮在此模式下隐藏。所有请求完全不发送Authorization头，即使本地还保存旧配对凭证也不会发送。测试模式收到HTTP 401时提示服务器未启用测试模式，不清除或撤销旧凭证。

专用目录默认PKM，不要设Vault根目录。Python导出测试库使用不同marker，不要把插件目录直接指向其已有笔记目录，建议全新测试Vault。

临时测试结束后请由管理员关闭服务器测试模式；关闭插件「临时免配对测试模式」后恢复原有配对界面和凭证校验。网页管理端「设备」生成配对码，填写设备名/配对码完成配对后同步。已有有效凭证可继续使用；配对模式401仍清除失效凭证并提示重新配对。

## 能力

- 只读接收正文/摘要/标签并转Markdown，原文折叠，哈希图片本地化。
- 版本化增量正文/附件校验；重复同步无变化不重复生成文件。
- 全部/选定数据源，空选不接收新数据，已有副本不删除。
- 本地修改检测，服务端新版本进入冲突副本，不静默覆盖。
- 前台定时5/15/30/60分钟，默认关闭；Obsidian打开可见、测试模式开启或已配对、当前HTTP批准时生效，退出后不承诺后台同步。
- 配对凭证交给Obsidian SecretStorage，data.json白名单只保存非敏感配置（含testMode布尔开关）和secret ID，不保存token或配对码。缺省testMode为true，显式false会保留。SecretStorage的具体跨设备保护与同步行为需以Obsidian版本为准，不声称插件自行实现系统密钥库。

## 安全与现阶段限制

HTTP会明文传输笔记，配对模式还会传输配对码和token。测试模式仍保留手动HTTP风险确认；当前服务器未经本次会话确认前，不启动HTTP定时同步。适合公开资料内测，正式使用需HTTPS。不要向其他不可信服务填本服务器配对码或凭证。

Obsidian requestUrl可兼容移动端，但当前公开API没有重定向控制或最终URL字段，尚无法独立保证宿主对跨origin跳转的凭据处理；不能称为生产级网络安全验收。现有服务器固定API不设置跳转，后续需宿主实测与HTTPS。

首次同步若文件写成功但初始索引失败，下次非空目录无index会拒绝接管。请保留文件并选择新空目录，不要直接删除已有笔记。已建立索引的部分写失败支持重试恢复；无整体多文件事务。同步期间不要同时编辑生成目录。

不下载原文远程图片，不执行原始HTML/插件代码，个人批注建议另建笔记。未提供双向编辑、自动删除、本地全文索引（使用Obsidian自身搜索）、手机后台常驻。插件data/secret在不同Vault和Obsidian同步服务下的行为仍需实际验证。
