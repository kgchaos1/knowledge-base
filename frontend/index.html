导入 Markdown/文本文件

支持 UTF-8 编码的 .md、.markdown、.txt，单个文件最大 2 MiB。不支持压缩包或本地图片自动上传；远程图片只是文本，不会备份。导入不会发送原文给 AI，可保存后在笔记卡片手动整理。笔记不关联数据源，在全部客户端的笔记范围内可见。

导入浏览器书签 HTML

可从 Chrome / Edge 书签管理器导出书签 HTML，再选择 UTF-8 编码的 .html 或 .htm 文件（最大 2 MiB，最多 1000 条）。仅保存标题和链接，不是网页全文；不会自动访问链接、下载图片或调用 AI。导入的笔记不关联数据源，全部客户端均可在「我的笔记」查看。

仅显示前 20 条标题、URL 和文件夹，均为文本，不会自动打开链接。
